# 班级与学生管理

## 班级字段
班级表 clazz 字段：id、name 班级名称、room 教室、begin_date 开课时间、end_date 结课时间、master_id 班主任员工ID、subject 学科。
学科 subject：1=Java，2=前端，3=大数据，4=Python，5=Go，6=嵌入式。
班级状态 status 不存入数据库，由 SQL 根据当前日期动态计算：
1=未开班（今天早于开课时间），2=在读中，3=已结课（今天晚于结课时间）。

## 班级规则
班级名称必填且唯一；开课时间、结课时间、学科必填。
结课时间必须晚于开课时间，否则提示「结课时间必须晚于开课时间」。
班主任从员工中选择，可以为空；候选列表接口 GET /clazzs/list 只返回 id 和 name。
删除班级前校验班级下是否存在学生，存在时提示「对不起，该班级下有学生，不能直接删除」。

## 学生字段
学生表 student 字段：id、name、no 学号、gender、phone、id_card 身份证号、is_college 是否院校、address 家庭住址、degree 学历、graduation_date 毕业时间、clazz_id 所属班级、violation_count 违纪次数、violation_score 违纪扣分。
学历 degree：1=初中，2=高中，3=大专，4=本科，5=硕士，6=博士。
是否院校 is_college：1=是，0=否。

## 学生规则
姓名、学号、性别、手机号、身份证号、是否院校、所属班级必填。
学号、手机号、身份证号全局唯一，冲突时分别提示「学号已存在」「手机号已存在」「身份证号已存在」。
学历、毕业时间、家庭住址可以为空。
学生查询支持姓名模糊、学历精确、班级名称模糊组合查询，分页默认 pageNum=1、pageSize=10。
学生批量删除使用重复参数，例如 DELETE /students?ids=1&ids=2。
